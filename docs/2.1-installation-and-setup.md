## Prerequisites

The project requires the following system dependencies:

| Requirement | Minimum Version      | Notes                                       |
| ----------- | -------------------- | ------------------------------------------- |
| Node.js     | 18.0.0               | Required for Vite and esbuild               |
| npm         | Bundled with Node.js | Package manager for dependency installation |
| Git         | Any recent version   | For cloning the repository                  |

The Node.js version requirement is enforced by multiple dependencies including Vite (>=18), esbuild (>=18), and various asset processing tools.

#### Key Transitive Dependencies

The installation automatically resolves the following critical transitive dependencies:

- **esbuild** (0.25.12): High-performance JavaScript/TypeScript compiler used by Vite
- **rollup** (4.53.3): Module bundler for production builds with tree-shaking
- **sharp** (0.34.5): Native image processing library for texture optimization
- **draco3dgltf** (1.5.7): Draco mesh compression for reducing GLB file sizes
- **meshoptimizer** (0.24.0): Mesh optimization algorithms for improved rendering performance

**Sources:** [package-lock.json2058-2097](https://github.com/amrayach/house-of-letters/blob/01a8e0f9/package-lock.json#L2058-L2097) [package-lock.json1140-1424](https://github.com/amrayach/house-of-letters/blob/01a8e0f9/package-lock.json#L1140-L1424) [package-lock.json1953-1959](https://github.com/amrayach/house-of-letters/blob/01a8e0f9/package-lock.json#L1953-L1959)

| ---------- | -------------------------------- | ----------------------------------------------- |

| `build`    | `vite build`                     | Creates optimized production build in `dist/`   |

### Platform-Specific Dependencies

The installation includes optional platform-specific binaries for:

- **esbuild**: Native binaries for faster compilation ([package-lock.json86-501](https://github.com/amrayach/house-of-letters/blob/01a8e0f9/package-lock.json#L86-L501))

These are automatically selected based on your operating system and CPU architecture. No manual intervention is required.
