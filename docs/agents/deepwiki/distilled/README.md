# DeepWiki Distilled Notes

This directory stores code-checked notes derived from `../raw/`.

Distillation rules:

- Distilled files are still secondary to local code and canonical repo docs.
- Every meaningful claim should trace back to both:
  - a raw DeepWiki capture
  - local code or checked-in repo docs
- If a DeepWiki claim is stale, incomplete, or wrong, record that in `mismatches-vs-code.md` instead of smoothing it over.
- Keep these notes compact enough to help future agents orient quickly without loading every raw file.

## Expected files

- `architecture-summary.md`
- `risky-areas.md`
- `confirmed-vs-unconfirmed.md`
- `mismatches-vs-code.md`

## Recommended use

1. Read the relevant shared doc under `docs/agents/shared/` first.
2. Read the matching distilled file here if a second opinion helps.
3. Open the matching raw file only when you need to inspect the original DeepWiki wording.

## Refresh rule

When raw captures change, refresh the distilled notes in the same pass and keep the mismatch ledger current.
